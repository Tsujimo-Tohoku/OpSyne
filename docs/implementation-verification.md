# ローカル v0.1 の検証記録

実施日: 2026-09-15。Windows / Python 3.12.14 / uv 0.12.13。

## 自動検査

`python scripts/dev.py run --locked python scripts/check.py` が終了コード0で完了。

| 検査 | 結果 |
|---|---|
| Ruff lint / format | 成功（82ファイル） |
| mypy strict | 成功（48ファイル） |
| import-linter | 4契約すべて成功 |
| pytest | 160件成功 |
| wheel / sdist ビルド | 成功 |

主な試験は、原本・配送待ち・取得位置の再起動、変換の適用条件と未知状態、
根拠の範囲とマスク、OpenAI構造化出力、別主体承認、計画改変・期限・版・世代の拒否、
実行前台帳、結果不明時の再送防止、独立確認、バックアップ・途中復元の拒否、
Windowsでのプロセス排他、保存と監査が同時に失敗してもワーカーが継続することを扱う。
後から追加された証拠を古い計画の確認で解決せず、LLM処理中に対象が変わった提案も拒否する。

配布物にWebのHTML/CSS/JavaScript、CLIエントリポイント、`py.typed` が含まれること、
`.env`・ローカルDB・キャッシュが含まれないことを検査した。

## ブラウザーで確認した範囲

隔離した合成データで、ログイン、役割切替、対象・観測源登録、Push取込、
変換承認・原本再解析、計画作成、自己承認拒否、別主体承認、操作実行、
独立確認後の案件解決を確認した。LLMキー不足のtaskは失敗として表示された。
HTMLを含むログは文字として表示され、ブラウザーでコードとして実行されなかった。
1280×720と390×844の画面を確認し、検証終了時のブラウザー警告・エラーはなかった。

標本検証APIと復元保留管理は自動テストで確認した。追加された標本検証ボタンの
実クリックと、復元保留解除のブラウザー操作は未確認（最終確認時にブラウザー接続が利用不可）。
